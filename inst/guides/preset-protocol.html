4. 量表与低/中/高区

默认 1–9：低 1–3、中 4–6、高 7–9。p_high 的分母是有效整数评分，「无法判断」不进入。

5 分和 7 分不用逐个手写区间。points = 5 或 scale_max = 5 会把低/中/高区改成 1–2 / 3 / 4–5，并把 median_min 改成 4、iqr_max 改成 1。7 分对应 1–2 / 3–5 / 6–7，median_min 为 6，iqr_max 为 1.5。比例阈值（如 0.80）不随点数改变。显式写出的区间或阈值仍以你写的为准。

p5 <- preset_protocol("clinical_consensus", points = 5)
p7 <- preset_protocol("clinical_consensus", scale_max = 7)
c(scale5 = paste(p5$scale_min, p5$scale_max, sep = "-"),
  high5 = paste(p5$high_range, collapse = "-"),
  median5 = p5$rules$median_min,
  high7 = paste(p7$high_range, collapse = "-"),
  median7 = p7$rules$median_min)
#>  scale5   high5 median5   high7 median7 
#>   "1-5"   "4-5"     "4"   "6-7"     "6"

5. 临床复合标准：high_pct、basic_pct、median_min、iqr_max、reject_pct

教学数据第 1 轮、同一批评分，只改 high_pct：

s1 <- summarize_items(consensus_demo, rounds = 1)
s1 <- s1[s1$dimension == "重要性", ]
cls80 <- classify_consensus(s1, p)
p70 <- preset_protocol("clinical_consensus", high_pct = 0.70)
cls70 <- classify_consensus(s1, p70)
table(cls80$class_zh)
#> 
#> 两极分化     临界 倾向排除 基本共识 未达共识 高度共识 
#>        3        1        1        1        9        5
table(cls70$class_zh)
#> 
#> 两极分化     临界 倾向排除 未达共识 高度共识 
#>        3        1        1        9        6

解读： 放宽 high_pct 会把部分「基本共识 / 临界」抬成「高度共识」。这正是事后改阈值的诱惑所在——也是 ACCORD 禁止的做法。真实研究若在发卷前就把高度共识写成 70% 或 85%，那就是本研究的初次锁定，不必写 rationale。锁定之后再改，才用 revise_protocol() 并写理由。

IQR 的作用：即使高区比例达标，离散过大也不能叫高度共识。

p_iqr <- preset_protocol("clinical_consensus", iqr_max = 1)
table(classify_consensus(s1, p_iqr)$class_zh)
#> 
#> 两极分化     临界 倾向排除 基本共识 未达共识 高度共识 
#>        3        1        1        5        9        1

reject_pct：多数人打 1–3 分才倾向排除，而不是「没过 80% 就删」。

6. 两极分化 polarization_threshold

默认两端同时 ≥25%。均数接近 5 往往是对抗，不是「大家觉得一般」。

7. COMET 70/15 四参数

pc <- preset_protocol("comet_cos")
unlist(pc$rules[c("comet_in_high", "comet_in_low_max", "comet_out_low", "comet_out_high_max")])
#>      comet_in_high   comet_in_low_max      comet_out_low comet_out_high_max 
#>               0.70               0.15               0.70               0.15

纳入：高区 ≥70% 且 低区 <15%。排除：低区 ≥70% 且 高区 <15%。两套都不满足 → 下一轮或会议，而不是自动删除。

9. 轮次与稳定性

  • max_rounds 默认 3，是上限不是义务。
  • stability_class_pct 默认 0.80：相邻轮分类不变的条目比例。
  • stability_median_delta 默认 1 分。
  • stability_high_pct_delta 默认 0.10（10 个百分点）。

三条同时满足才建议终止。Wilcoxon P>0.05 不能单独定义稳定。刚跨过 80% 就停，可能过早。

10. cv_max、ranking_topk、rationale、locked

  • cv_max：仅指标体系；CV 是均数补充。
  • ranking_topk：仅排序函数的 Top-k。
  • rationale：初次锁定不必填。锁定后再改参数时，revise_protocol() 必填；报告打印「方案偏离初次锁定」。
  • locked = TRUE：分析函数不得把阈值当参数回改。[classify_consensus()] 没有阈值参数，就是为了堵住这条路。
p_first <- preset_protocol("clinical_consensus", high_pct = 0.85)
p_first$modified_from_preset
#> [1] FALSE
p2 <- revise_protocol(
  p_first,
  high_pct = 0.90,
  rationale = "方案锁定后、看见评分前，将高度共识阈值从 0.85 提高到 0.90。"
)
c(modified = p2$modified_from_preset, rationale = p2$rationale)
#>                                                      modified 
#>                                                        "TRUE" 
#>                                                     rationale 
#> "方案锁定后、看见评分前，将高度共识阈值从 0.85 提高到 0.90。"

11. 接到问卷与三轮流程

参数锁定之后：

  1. [delphi_blueprint()] 生成第 1 轮 docx/xlsx；
  2. [read_survey_xlsx()] 回读；
  3. [analyze_delphi()] / [run_delphi()]；
  4. [next_round_questionnaire()] 生成第 2、第 3 轮。
