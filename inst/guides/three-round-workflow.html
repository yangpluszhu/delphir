Ming Yang

2026-09-17

1. 这份文档解决什么问题

从空白方案走完 不少于 3 轮 的 Modified Delphi：锁定阈值 → 生成 docx/xlsx 问卷 → 回读 xlsx → 逐轮分析 → 自动生成下一轮 → 终稿报告（含 docx），并对报告每一节做方法学解读。

参数含义见 vignette("preset-protocol", package = "delphir")。数据为包内 consensus_3round_demo（模拟，含脱落、无法判断、临界与两极分化）。

#> 
#> 高度共识 基本共识 两极分化     临界 未达共识 
#>        3        2        1        1        5

解读这一轮的表：

  • 参与度：回收率是积极系数，不是共识。
  • Median / IQR / p_high：主指标。均数、CV、Kendall W 只能当补充。
  • 高度共识：可考虑第 2 轮不重评（查阅即可）。
  • 基本共识：保留，但与高度共识分列。
  • 临界 / 未达共识：必须带反馈进入第 2 轮。
  • 两极分化：不要写成「均数约 5，意见一般」。
  • 无法判断：报告人数，不进 1–9 分母。
  • 权威系数：专家级一次自评，不加权。
head(accord_checklist(res1)[, c("id", "status")], 6)
#>   id status
#> 1 T1    Yes
#> 2 I1    Yes
#> 3 I2    Yes
#> 4 I3    Yes
#> 5 M1 Unsure
#> 6 M2    Yes

中间报告对照清单时大量 Unsure 是正常的——软件不能假装伦理批件已经写进论文。

9. 终稿每一节读什么、不能读成什么

下面按报告结构解读。可用 res3 中的对象对照。

9.1 报告性质与范围

必须能回答：为什么用共识方法、目的、目标使用者、地理范围。缺一项，审稿人会问。Delphi 不能代替系统评价。

9.2 预设方案参数表

protocol_table(res3$study$protocol) 应出现全部阈值。若 modified_from_preset 为 TRUE 却没有 rationale，属于方法学缺陷。

9.3 专家构成与权威系数

目的抽样不是随机样本。Cr 是专家对主题的一次自评：组均数 ≥0.70 仅供国内发表参考，不是 DCAT 核心，更不能加权 Likert。

if (!is.null(res3$authority)) attr(res3$authority, "overall")[c("mean_cr", "pct_ok")]
#> $mean_cr
#> [1] 0.8375
#> 
#> $pct_ok
#> [1] 95.83333

9.4 各轮问卷内容

第 1 轮：规则原文 + 权威系数 + 全部条目。
第 2–3 轮：本人上轮分、组 Median/IQR、高区、匿名意见；无 Ca/Cs。
这对应 DCAT 的受控反馈。缺少「本人上轮评分」的反馈不算合格 Delphi。

9.5 逐轮调查结果

过程必须透明：不能只报第 3 轮。主指标永远是 Median、IQR、高/低区比例。n_unable 要单独在。

9.6 稳定性、分层、脱落、意见、Kendall W

  • 稳定性：分类不变 + Median + 高区比例；P 值依赖样本量。
  • 分层：总体过线不等于每一组过线（尤其患者组）。
  • 脱落：比较完成者与脱落者在上一轮的分布。
  • 意见：主题需预先编码，不是事后用共识率代替定性。
  • Kendall W：排序协调性，不是条目共识。

9.7 最终结果与会议建议

已达高度共识的条目不要在少数人参加的会议上推翻大样本匿名结果。会议聚焦临界、无共识、组间相反、改文字。稳定分歧 = 未达共识。

if (!is.null(res3$stopping)) {
  res3$stopping[c("recommend_stop", "current_round", "max_rounds")]

9.8 ACCORD / DCAT / CREDES

Unsure 必须由作者在论文里补写。DCAT 四个核心项：匿名、迭代、受控反馈、统计汇总。任一为 No，应评为关键缺陷。

报告末尾列出 Diamond 2014、Hasson 2000、ACCORD、DCAT、CREDES、RAND 手册、COMET Handbook、曾光赋分表及 citation("delphir")。引用规范不等于已经满足规范。

10. 最小可复现代码

protocol <- preset_protocol("clinical_consensus")
bp <- delphi_blueprint(protocol, panel, items, meta)
delphi_questionnaire(bp, round = 1, format = "both", file = "r1")
# 专家填写 r1/*.xlsx 后：
study <- read_survey_xlsx("r1", study = bp)
res1 <- run_delphi(study, round = 1, report = TRUE, file = "round1.docx")
next_round_questionnaire(res1, format = "both", file = "r2")
# 重复至第 3 轮后：
res <- run_delphi(study3, report = TRUE, format = "both", file = "final")

常见错误仍是：事后改阈值、用 Cr 加权、把「不熟」录成 5 分、删除脱落者历史评分、反复投票直到全部「达成共识」。
