教学文档 8：第一轮新增条目，从问卷到三轮报告

Ming Yang

2026-10-04

1. 这份文档在做什么

改良 Delphi 往往先根据文献、指南和访谈，准备好一份候选条目，再请专家打分。第一轮结束以后，专家仍然可以指出遗漏。高质量的做法不是「写到了就加进去」，而是事先规定：怎样判断它是不是一条新的评价概念，什么情况下可以进入下一轮，以及新条目至少还要再评一轮。

下面用一个完整、可重复的教学案例走通不少于 3 轮：

建立适用于中医药治疗成人慢性心力衰竭临床研究的核心疗效指标集。

要评价的问题是：哪些结局重要到应当进入核心指标集。范围只包括临床疗效，不包括住院费用这类卫生经济学指标。数据是模拟的，用来演示方法，不能当作临床推荐。

怎么读： 共识规则是 COMET 常用的 70/15。评分 7–9 的人至少占 70%，同时评分 1–3 的人不到 15%，才叫纳入共识。反过来，1–3 分至少 70% 且 7–9 分不到 15%，才叫排除共识。其余是未达共识。这些数字在发问卷之前就锁定了，看到结果以后不能再改。

新增条目另有一套同样事先锁定的规则：至少 2 名专家各自独立提出，或者只有 1 名专家提出、但已有文献、访谈、指南或重要临床依据。软件只执行这套规则，不会把专家的原话自动改写成条目。

2. 第 0 步：初始候选池和第一轮问卷

初始池有 26 项，来自前期证据综合。里面已经有「心衰住院」「健康相关生活质量」「中医证候总积分」。还没有「患者总体改善感受」「睡眠质量」「活动后呼吸困难恢复情况」。这三句要等第一轮开放题之后再审查，不能提前放进问卷冒充已有条目。

怎么读： 第 1 轮问卷做两件事。一是请专家对 26 项按 1–9 分评价重要性，不了解就选「无法判断」，不要填成中间的 5 分。二是用结构化开放题询问有没有遗漏：名称、含义、理由、与现有条目的区别、依据，每人最多 5 项。不要只留一句「还有其他意见吗」。

xlsx 里黄色格子是要填写的。另有一张「新增建议」表。docx 给专家阅读，xlsx 给数据回收。

下面用已经填好的模拟答卷演示回读。真实研究里，把专家交回的 xlsx 放在同一位置即可。

filled <- tempfile(fileext = ".xlsx")
delphi_questionnaire(round1, round = 1, format = "xlsx", file = filled, prefill = TRUE)
got <- read_survey_xlsx(filled)
c(nrow(got$ratings), nrow(got$suggestions))
#> [1] 780  27

怎么读： 评分是长表：一位专家、一条目、一轮、一个维度，占一行。30 人乘 26 项，应当是 780 行。「新增建议」里同一位专家可以把「睡眠」写两次，回读会保留两行；审查时仍只算 1 个人。原始句子的条数，也不等于归并以后的概念个数。

3. 第一轮之后：编码、五问、双通道

研究组先阅读原始句子，再归并成概念。两名研究者独立编码。不一致时，由第三个人裁决。编码类别是：新条目、重复、上下位概念、原条目修改、测量工具、测量时间点、范围外、无法形成可评价概念。

本案例归并以后的独立提出人数是：患者总体改善感受 8 人，睡眠质量 1 人，活动后呼吸困难恢复 3 人，舌色 2 人，脉象 2 人，30 日再住院 4 人，医疗费用 2 人，MLHFQ 3 人。另有 1 条只建议把说法改得更顺，用来对照「文字修改」。睡眠质量那一行被同一位患者代表写了两次，人数仍然是 1。

screen <- screen_new_items(

怎么读，逐条对应审查结果：

  • 患者总体改善感受：8 人独立提出，原池里没有同一概念，进入下一轮。这是通道 A。
  • 活动后呼吸困难恢复情况：有人认为它只是「呼吸困难」的下位概念，另一人认为活动后多久能缓过来是另一个概念。第三人结合患者访谈，裁决为独立概念。3 人提出，进入下一轮。进入评分时的名称是「活动后呼吸困难恢复情况」。
  • 睡眠质量：只有 1 人提出。若规定「必须至少 2 人」，它会被删掉。前期 20 名患者访谈里有 7 人主动说到夜间憋醒、不能平卧、睡眠受影响，所以走通道 B，仍然进入下一轮。一个人提到的次数少，不等于这件事对患者不重要。
  • 30 日再住院：4 人提到，但原池已有「心衰住院」。这是测量时间窗，不另设一条结局。
  • MLHFQ：3 人提到。它是明尼苏达心衰生活质量量表，是测量工具。对应的结局概念仍然是已有的「健康相关生活质量」。工具留到以后选择「怎么测量」时再用。
  • 舌色、脉象：各有 2 人提到，但证候评价已经包含舌质、舌苔和脉象。再单列会造成内容重叠，合并进「中医证候总积分」，不新增。
  • 医疗费用：有 2 人提出，人数够了，可是本研究只做临床疗效，不做卫生经济学。人数不能凌驾于范围。不进入下一轮，理由要保留。
  • 把「运动耐量」说成「运动能力」：只是用语更顺，评价的还是同一个概念。保留原编号，不重新开始计轮次。

所以第二轮不是 26 加 8 等于 34，而是 26 加 3 等于 29。没有进入的建议也留在审查表和变更日志里。

4. 第 1 轮评分说明什么

res1 <- analyze_delphi(pooled)
round1_cls <- res1$classification
round1_cls <- round1_cls[round1_cls$round == 1 & round1_cls$dimension == "重要性", ]
table(round1_cls$class_zh)
#> 
#> 纳入共识 排除共识 未达共识 
#>       22        1        3

怎么读： 这一轮 26 项里，有的已经达到 70/15，有的还没有，有的多数人打在低分区。这是中间结果。原条目还要在第 2 轮看到全组分布和自己的分数以后再评一次。三个新条目这一轮还没有分数，不能给它们编造中位数或百分比。

权威系数、回收率和 Kendall 协调系数如果出现在输出里，只说明专家是否回卷、自评是否熟悉、整体排序是否齐。它们不决定某一条进不进核心指标集。

5. 第 2 轮：原条目看反馈，新条目第一次打分

第 2 轮对原来的 26 项，给出本人上一轮分数、全组中位数、四分位距、7–9 分比例、1–3 分比例和匿名意见，然后请专家重新评分。对 3 个新条目，问卷写明「本轮为首次评分」，不出现上一轮统计。

md2 <- delphi_questionnaire(res1, round = 2, expert_id = "E01", items = "all")
stopifnot(grepl("首次评分", md2), grepl("NEW-02", md2))
dir2 <- tempfile("chf-r2-")
dir.create(dir2)
delphi_questionnaire(res1, round = 2, format = "xlsx", file = dir2, items = "all")
delphi_questionnaire(res1, round = 2, format = "docx", file = dir2,
                     expert_id = "E01", items = "all")
basename(list.files(dir2))
#> [1] "round2.docx" "round2.xlsx"

怎么读： E01 的问卷里，旧条目有一组统计数字；睡眠质量、患者总体改善感受和活动后恢复只有评分尺。空白不是 0 分，也不是「大家觉得一般」。xlsx 里这些行的 first_scoring 为 TRUE，中位数一列是空的。

模拟的第 2 轮答卷已经按 30 人能实现的最接近比例生成。文中的 90%、77%、63% 在 30 人里对应 27/30、23/30、19/30。

src2 <- simulate_chf_new_items(up_to_round = 2)
study2 <- update_delphi_study(

  ratings = src2$ratings[src2$ratings$round == 2, ],
  comments = src2$comments
)
res2 <- analyze_delphi(study2)

                 show2$dimension == "重要性", ]
show2[, c("item_id", "p_high", "p_low", "class_zh", "action", "n_scoring_rounds", "provisional")]
#>    item_id   p_high     p_low     class_zh  action n_scoring_rounds provisional
#> 53  NEW-01 90.00000  3.333333 暂时纳入共识 rescore                1        TRUE
#> 54  NEW-02 76.66667  6.666667 暂时纳入共识 rescore                1        TRUE
#> 55  NEW-03 63.33333 10.000000     未达共识 discuss                1       FALSE

怎么读：

  • 患者总体改善感受：7–9 分约 90%，1–3 分约 3%。形式上已经达到纳入线，但分类写成「暂时纳入共识」，动作是再评。它只被打过一次分。
  • 睡眠质量：7–9 分约 77%，1–3 分约 7%。同样只是暂时纳入。支持意见认为睡眠受夜间呼吸困难影响，是患者能感觉到的获益；反对意见认为睡眠还受焦虑、环境和合并疾病影响，特异性不够。这些匿名意见会写进第 3 轮反馈。
  • 活动后呼吸困难恢复情况：7–9 分约 63%，没有达到 70%。这是未达共识，不是暂时纳入。

第 2 轮分数高，不能直接写进核心指标集。Delphi 要的是：评分，看到群体结果，再想一次，再评分。

6. 第 3 轮：只再评还没有完成迭代的条目

第 3 轮不再要求所有已经稳定纳入或明确排除的原条目重答。需要再评的是：3 个新条目、仍未达共识的原条目。实质性修改的新版本也会在这里重评；本案例的主池里没有这类新版本。

md3 <- delphi_questionnaire(res2, round = 3, expert_id = "E01", items = "iteration")
stopifnot(grepl("NEW-01", md3), grepl("CHF-11", md3))
dir3 <- tempfile("chf-r3-")
dir.create(dir3)
delphi_questionnaire(res2, round = 3, format = "xlsx", file = dir3, items = "iteration")
delphi_questionnaire(res2, round = 3, format = "docx", file = dir3,
                     expert_id = "E01", items = "iteration")
basename(list.files(dir3))
#> [1] "round3.docx" "round3.xlsx"

怎么读： 新条目这一次能看到第 2 轮的中位数、区间比例，以及匿名的支持和反对意见。问卷会提醒：上一轮只是第一次评分，过线也还不是最终纳入。已经在第 2 轮明确排除的条目，例如多数人认为不适合进入核心集的「体重增加」，不再拿回来重投，直到表面一致。

怎么读：

  • 患者总体改善感受：第 3 轮 7–9 分约 93%，1–3 分 0。已经有两轮评分，最终为纳入共识，可以进入候选核心指标集。
  • 睡眠质量：7–9 分约 83%，1–3 分约 7%。同样最终纳入。
  • 活动后呼吸困难恢复情况：7–9 分约 67%，1–3 分约 13%。仍未达到预设的 70/15。规范的说法是：未达到预设共识阈值。它不是「专家认为不重要」，也不是「专家反对」。
  • 仍有个别原条目，例如气虚症状，三轮以后也没有过线。它们进入会议讨论的 C 类，而不是被悄悄删掉。
  • 第 2 轮已经明确排除的条目保持排除。会议原则上不把 B 类再翻过来。

30 人无法刚好得到文中每一个一位小数。23/30 是 76.7%，对应叙述中的 77%；20/30 是 66.7%，对应 67%。过线与否和案例一致。

报告按锁定方案生成，包含方案参数、各轮结果、新增条目审查、变更日志、会议分组，以及 ACCORD、DCAT、CREDES 对照。Word 与网页使用同一模板。

怎么读报告时，建议按这个顺序：

  1. 先看目的和范围。本题问的是核心疗效结局，不是所有看起来重要的指标，也不是测量工具或住院费用。
  2. 再看方案表。70/15、至少 2 名独立专家或 1 名加外部证据、新条目必须再迭代一轮，都应当能在表里找到，并且标成发问卷前就锁定。
  3. 看概念审查。每一条建议都有去向。进入下一轮的只有 3 条。
  4. 看第 2 轮时，把「暂时纳入共识」读成「第一次评分过线」，不要读成「已经进入核心集」。
  5. 看第 3 轮时，用最终分类。未达阈值的条目保持「未达共识」。
  6. 看会议分组。C 类可以讨论。会上新冒出来的条目不能当场拍板。
  7. 权威系数、积极系数、Kendall 协调系数和变异系数放在补充位置。它们描述这批专家和整体协调，不代替条目级的中位数、四分位距和高低区比例。平均分高也不等于达成共识。

模拟数据生成的报告不能当作真实心衰核心指标集发布。真实研究还要写明专家如何抽样、伦理、资金和利益冲突，这些清单里会标成需要作者补写的项目。

9. 换一个研究时，最小代码是什么

诊断标准、证候标准、疗效评价标准和核心指标集都可以用同一套新增规则。共识阈值随场景变化：核心指标集用 70/15；医学共识预设是高区比例、中位数和四分位距。新增规则不要等到看见开放题以后再写。

protocol <- preset_protocol("comet_cos")
bp <- delphi_blueprint(protocol, panel, items, meta)
delphi_questionnaire(bp, round = 1, format = "both", file = "r1")
# 专家交回 xlsx 后：
wave1 <- read_survey_xlsx("r1", study = bp)
# 研究组编码 concept_review 后：
screen <- screen_new_items(wave1$suggestions, concept_review, wave1$protocol, wave1$items)
study <- update_delphi_study(wave1, items = screen$admitted)
res1 <- analyze_delphi(study)
delphi_questionnaire(res1, round = 2, format = "both", file = "r2", items = "all")
# 第 2 轮回收后分析。新条目若只是暂时纳入，第 3 轮继续：
delphi_questionnaire(res2, round = 3, format = "both", file = "r3", items = "iteration")
res <- analyze_delphi(study3)
delphi_report(res, file = "final.docx", format = "docx")

第 2 轮用 items = "all"，让原条目都看到反馈。第 3 轮用 items = "iteration"，只再评新条目、未达共识的条目和实质性修改。若方案规定每一轮都重评全部条目，两轮都用 items = "all" 也可以，只是专家负担更大。
