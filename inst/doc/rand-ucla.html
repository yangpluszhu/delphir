Ming Yang

2026-10-04

1. 为什么这不是普通 Delphi

Delphi 的核心逻辑是：匿名反复评分 → 反馈 → 再评分 → 意见逐渐收敛。它适合共识条目、指标选择、优先级、核心结局和定义。

RAND/UCLA Appropriateness Method（RAM） 要回答的是另一个问题：

某临床措施在特定场景下是否“适宜”？

适宜指：对普通患者、由普通医生在普通机构实施时，预期获益超过预期伤害的程度（通常不考虑成本）。Fitch 等（2001）手册是本教程的方法学依据。

关键差别：

医学共识 Delphi RAND/UCLA
目标 条目是否纳入共识 指征是否适宜 / 不确定 / 不适宜
面板 常 30–80+ 人 经典 9 人左右（约 7–15）
分歧 用 IQR、赞同率 经典两端规则 + IPRAS / DI
会议 讨论临界条目 第 1 轮后正式讨论，再独立复评
强迫一致 仍常被误用 明确不强迫共识

2. 流程概览（按手册）

  1. 选主题，做文献综述并形成指征清单（临床场景 × 操作）；
  2. 组成多学科面板（专科 + 全科 + 必要时方法学）；
  3. 第 1 轮：独立、匿名、邮寄/在线评分；
  4. 个性化反馈：本人评分 + 全组分布；
  5. 面对面或在线会议，讨论分歧，再独立评分；
  6. 用 Median + 分歧判定 Appropriate / Uncertain / Inappropriate；
  7. 可选第 3 轮：只对“适宜”的指征评 Necessity（必要性）。

DCAT 将 RAM 视为一种 Modified Delphi：轮次有限、中间有讨论、9 分量表、会前必须提供证据。

#>   量表: 1–9  (低 1–3 / 中 4–6 / 高 7–9)
#>   锁定: 是
protocol$rand
#> $disagreement
#> [1] "both"
#> 
#> $di_threshold
#> [1] 1

判定规则（写入方案，分析时不得改）：

  • Median 1–3 且无分歧 → Inappropriate
  • Median 7–9 且无分歧 → Appropriate
  • Median 4–6，或任何分歧 → Uncertain

分歧有两套定义，本包默认都算：

  1. 经典： 约三分之一评 1–3 且约三分之一评 7–9（9 人面板即各 ≥3 人）；
  2. IPRAS / DI（Fitch 2001）：

[ IPR = P_{70}-P_{30}, AI = |-5|, IPRAS = 2.35 + 1.5AI, DI = IPR/IPRAS ]

DI ≥ 1 为分歧。IPRAS 可推广到非 3 倍数的面板。

高度一致：

两端拉扯：

rand_disagreement(c(1, 1, 2, 2, 5, 8, 9, 9, 9))
#>   n_valid p30 p70 ipr iprcp  ai ipras       di n_low n_high classic_threshold
#> 1       9   2 8.6 6.6   5.3 0.3   2.8 2.357143     4      4                 3
#>   classic_disagreement ipras_disagreement disagreement
#> 1                 TRUE               TRUE         TRUE

解读：

  • 第一组 IPR 很小，DI 远小于 1，无分歧。
  • 第二组两端都有多人，经典规则与 DI 通常同时报警。
  • 若 Median 仍是 7 或 8，只要存在分歧，最终仍是 Uncertain。这是 RAM 与“只看中位数”的 Delphi 最重要的不同。

手册强调：两轮的目的是区分“真实临床分歧”和“疲劳/误解造成的假分歧”，不是把人推向一致。

解读输出：

  • median_iqr：位置。7–9 区只是“候选适宜”，还要过分歧关。

解读最终三类：

  • 适宜： 可以进入后续“该做”清单；若研究设计含 Necessity，只对这些指征再评“不做是否不可接受”。

13. 本场景常见错误

  1. 用 40 人开放 Delphi 的 75% 规则套在 RAM 上；
  2. 只看 Median，忽略分歧，把两极条目写成“适宜”；
  3. 开会举手“统一意见”，破坏独立复评；
  4. 把 Uncertain 当成失败，反复投到出现共识；
  5. 面板全是实施该操作的专科医生，缺少全科或相邻学科；
  6. 第 1 轮前不提供证据综述；
  7. 指征过于笼统，无法对应真实患者；
  8. 用 Kendall W 或 Cr 代替 DI。
